# Telecom BDD Automation

Projeto de automacao BDD para validar o fluxo de ativacao de SIM card usando Cucumber.js e Chai.

## Requisitos

- Node.js
- npm

## Instalacao

```bash
npm install
```

## Executar testes

```bash
npm test
```

No PowerShell, se a politica de execucao bloquear `npm.ps1`, use:

```powershell
npm.cmd test
```
